# qa-manual-login
Proyecto de QA Manual - Pruebas funcionales de Login


1- Descripción

Proyecto de QA Manual realizado para practicar el proceso de testing de un formulario de inicio de sesión.

2- Objetivo

Verificar que el login funcione correctamente con diferentes combinaciones de datos válidos e inválidos.

3- Pruebas realizadas

* Login con usuario y contraseña válidos.
* Login con contraseña incorrecta.
* Login con usuario incorrecto.
* Campos obligatorios vacíos.
* Validación de mensajes de error.
* Validación de acceso al sistema.

4- Tipos de pruebas

* Pruebas funcionales.
* Pruebas negativas.
* Pruebas de validación.
* Pruebas de regresión.

5- Documentación

* Plan de pruebas.
* Casos de prueba.
* Reporte de bugs.
* Evidencias de ejecución.

6- Resultado

Se ejecutaron los casos de prueba y se registraron los resultados obtenidos.

* GitHub
* Excel
* Navegador web
* Testing Manual
